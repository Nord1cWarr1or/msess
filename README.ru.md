# msess

**[English](README.md)** | **Русский**

msess — выборщик сессий MiMoCode на fzf. Показывает **все** сессии из всех
директорий (встроенный `/sessions` в TUI показывает только сессии текущей
директории), ищет по заголовкам и по содержимому переписок, открывает сессию
прямо в текущем терминале.

## Быстрый старт

```bash
msess
```

Пикер открывается поверх терминала: фильтр — набором текста, `Enter` —
открыть сессию.

## Установка

```bash
cp msess ~/.local/bin/msess && chmod +x ~/.local/bin/msess
```

После правок скрипта — повторить копию (или сделать симлинк `ln -sf`).

## Использование

| Аргумент | Действие |
|----------|----------|
| *(нет)* | открыть пикер сессий |
| `-h`, `--help` | показать справку и выйти |

### Клавиши

| Клавиша | Действие |
|---------|----------|
| `Enter` | открыть сессию (`exec mimo -s <id>`) в папке по режиму `Ctrl-F` |
| `Ctrl-R` | переименовать сессию |
| `Ctrl-D` | удалить отмеченные сессии (или текущую); `Enter` — подтвердить, `n` — отмена |
| `Tab` | отметить сессию для группового удаления |
| `Ctrl-T` | режим: заголовки ⇄ поиск по содержимому |
| `Ctrl-F` | папка открытия: **текущая** ⇄ **сохранённая папка сессии** |
| `Esc` / `Ctrl-C` | выход |

В режиме «папка сессии» сессия открывается там, где её открывали в последний
раз (если папка удалена — в текущей). При открытии сессии в новом месте путь
запоминается: `session.directory` обновляется на фактическую папку.

Все действия — переименование, удаление и оба переключателя — выполняются
не выходя из списка: пикер — один процесс fzf, список обновляется на месте,
курсор и поисковый запрос сохраняются всегда. Выбранные режимы (`Ctrl-T`,
`Ctrl-F`) запоминаются между запусками. Отметки (`Tab`) сбрасываются после
обновления списка.

В режиме поиска по содержимому (`fts>`) запрос уходит в полнотекстовый
индекс (FTS5) — ищет по тому, **что обсуждалось** в сессиях, с подсветкой
совпадений. Preview справа: **сверху** — начало сессии (первые сообщения;
короткие сессии — целиком), на середине — разделительная черта, под ней
последние сообщения и совпадения, растущие вниз к нижней рамке.

## Конфигурация

Путь к базе разрешается в заведомом порядке: `$MIMOCODE_DB` → дефолтный путь
(учитывает `$MIMOCODE_HOME`) → `mimo db path`.

| Переменная | Назначение | По умолчанию |
|------------|------------|--------------|
| `MIMOCODE_DB` | путь к `mimocode.db` | определяется автоматически |
| `MIMOCODE_HOME` | домашняя директория MiMoCode; сдвигает дефолтный путь базы | `~/.local/share/mimocode` |
| `MSESS_STATE` | файл состояния двух режимов пикера | `~/.local/state/msess/state` |

Файл состояния перезаписывается атомарно при каждом переключении,
в том числе изнутри fzf.

## Данные

- Читает: SQLite `~/.local/share/mimocode/mimocode.db` — таблицу `session`
  для списка (CLI `mimo session list` — фолбэк, если база недоступна);
  полнотекстовый индекс `history_fts` для поиска по содержимому,
  отфильтрованный до `user_text`/`assistant_text`; строки `message`/`part`
  для preview.
- Пишет: ровно две записи — `UPDATE session SET title=?` (переименование)
  и `UPDATE session SET directory=?` (фиксация папки последнего открытия).
- Никогда: прямые `DELETE FROM` — удаление только через официальный
  `mimo session delete`.

## Требования

- bash
- fzf 0.36+ (проверяется при запуске)
- python3 3.10+
- MiMoCode CLI (`mimo`)

Проверено на: fzf 0.74.3, Python 3.14, MiMoCode 0.1.13.
