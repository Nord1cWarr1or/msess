# msess

Быстрый выборщик сессий MiMoCode (fzf). Показывает **все** сессии из всех
директорий (встроенный `/sessions` в TUI показывает только сессии текущей
директории), ищет по заголовкам и по содержимому переписок, открывает сессию
прямо в текущем терминале.

## Установка

```bash
cp msess ~/.local/bin/msess && chmod +x ~/.local/bin/msess
```

После правок скрипта — повторить копию (или сделать симлинк `ln -sf`).

## Использование

```bash
msess
```

| Клавиша | Действие |
|---------|----------|
| `Enter` | открыть сессию (`exec mimo -s <id>`) в папке по режиму `Ctrl-F` |
| `Ctrl-R` | переименовать сессию |
| `Ctrl-D` | удалить сессию (подтверждение `y/N`) |
| `Ctrl-T` | режим: заголовки ⇄ поиск по содержимому |
| `Ctrl-F` | папка открытия: **текущая** ⇄ **сохранённая папка сессии** |
| `Esc` / `Ctrl-C` | выход |

В режиме «папка сессии» сессия открывается там, где её открывали в
последний раз (если папка удалена — в текущей). При открытии сессии
в новом месте путь запоминается: `session.directory` обновляется на
фактическую папку.

Переименование и удаление выполняются не выходя из списка: подтверждение
открывается поверх fzf, затем список обновляется — курсор остаётся на той же
позиции, поисковый запрос не сбрасывается. Выбранные режимы (`Ctrl-T`,
`Ctrl-F`) запоминаются между запусками.

В режиме поиска по содержимому (`fts>`) запрос уходит в полнотекстовый
индекс (FTS5) — ищет по тому, **что обсуждалось** в сессиях, с подсветкой
совпадений. Preview справа: **сверху** — «начало» сессии (первые сообщения;
в коротких — все), **на середине — разделительная черта**, под ней
«последние» и совпадения, растущие вниз к нижней рамке.

## Данные

- Список: SQLite `~/.local/share/mimocode/mimocode.db`, таблица `session`
  (только чтение). CLI `mimo session list` — фолбэк, если база недоступна.
- Поиск: `history_fts` (FTS5), только `user_text`/`assistant_text`.
- Запись в базу — ровно две: `UPDATE session.title` (переименование) и
  `UPDATE session.directory` (фиксация папки последнего открытия).
  Удаление — только через официальный `mimo session delete`.
- Путь к базе: `$MIMOCODE_DB` → дефолт (`$MIMOCODE_HOME` учитывается) →
  `mimo db path`.
- Настройки (режим поиска и папки открытия): файл состояния
  `~/.local/state/msess/state`, переопределяется `MSESS_STATE`.

## Требования

bash, fzf ≥ 0.36, python3 ≥ 3.10, mimo CLI. Проверено на fzf 0.74.3,
python 3.14, MiMoCode 0.1.13.
